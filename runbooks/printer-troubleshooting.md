# Runbook: printer not printing

## Triage
1. Confirm printer name/location and affected user(s).
2. Determine whether one user, one device or everyone is affected.
3. Record application, error message and time.
4. Check power, display, paper, toner and visible error indicators.

## Checks
- Confirm endpoint is connected to the expected network.
- Confirm selected/default printer.
- Check the print queue for stuck jobs.
- Check printer status and connectivity.
- If authorised, clear the affected user's stuck job and retry with a test page.
- Check whether other users can print.

## Resolution
Apply only approved driver or queue changes. Avoid restarting shared print services during business hours without assessing impact and approval. Print a test page and ask the user to verify the required application output.

## Escalate when
- Hardware reports a fault.
- Multiple users or printers are affected.
- Network or print-server services appear unavailable.
- A driver change requires broader deployment.

Record scope, checks, changes, test result and user confirmation.

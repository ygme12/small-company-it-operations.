# Implementation evidence

Store sanitised evidence here, grouped by task or milestone.

Suggested folders:
- `01-environment/`
- `02-glpi-deployment/`
- `03-ticket-workflows/`
- `04-asset-inventory/`
- `05-identity-lifecycle/`
- `06-powershell/`
- `07-reporting/`

For each evidence item, describe what was configured/tested, which environment was used (Azure Server 2025 or separate physical Server 2022), steps performed, expected and actual result, validation method and limitations.

Only add genuine screenshots and outputs from completed work. Redact secrets, personal data, tenant identifiers and internal details. Do not upload VM disks, memory dumps, credentials or private keys.
